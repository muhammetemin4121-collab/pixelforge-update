# PixelForge Studio — resmi güncelleme kanalı

Bu depo **PixelForge Studio** uygulamasının **resmi otomatik güncelleme** dosyalarını barındırır.

## Bu nedir?
- `update.json` — sürüm bilgisi (uygulama burayı kontrol eder)
- `PixelForgeSetup.exe` — resmi Windows kurulum dosyası

## Bu nedir değil?
- Kırık / crack / keygen / warez **değildir**
- Adobe Photoshop veya başka bir ürünün kopyası **değildir**
- Üçüncü taraf yazılım dağıtımı **değildir**

PixelForge Studio, bağımsız olarak geliştirilmiş yerel bir görüntü düzenleyicidir.  
Bu dosyalar yalnızca uygulamanın kendi güncelleme sistemi içindir.

## Doğrulama
Uygulama içinden: **Yardım → Güncellemeleri Denetle**
